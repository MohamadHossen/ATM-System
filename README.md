# نظام الصراف الآلي (ATM)

برنامج C++ بسيط يحاكي نظام الصراف الآلي مع العمليات المصرفية الأساسية.

## المميزات

- **نظام تسجيل الدخول**: يمكن للمستخدمين تسجيل الدخول باستخدام رقم الحساب والرقم السري
- **سحب سريع**: سحب مبالغ محددة مسبقاً (20، 50، 100، 200، 400، 600، 800، 1000)
- **سحب عادي**: سحب أي مبلغ من مضاعفات الرقم 5
- **إيداع**: إضافة أموال إلى الحساب
- **الاستعلام عن الرصيد**: عرض الرصيد الحالي
- **تسجيل الخروج**: العودة إلى شاشة تسجيل الدخول

## طريقة الاستخدام

1. **تسجيل الدخول**
   - أدخل رقم الحساب
   - أدخل الرقم السري
   - في حالة فشل تسجيل الدخول، سيتم مطالبتك بالمحاولة مرة أخرى

2. **قائمة الخيارات الرئيسية**
   - اضغط `1` للسحب السريع
   - اضغط `2` للسحب العادي
   - اضغط `3` للإيداع
   - اضغط `4` للاستعلام عن الرصيد
   - اضغط `5` لتسجيل الخروج

3. **السحب السريع**
   - اختر من المبالغ المحددة مسبقاً (1-8)
   - اضغط `9` للخروج دون سحب

4. **السحب العادي**
   - أدخل أي مبلغ من مضاعفات الرقم 5
   - سيتحقق النظام من توفر الرصيد الكافي

5. **الإيداع**
   - أدخل مبلغ موجب للإيداع

## هيكل الملفات

- `Clients.txt`: يخزن جميع بيانات العملاء بالصيغة التالية:
- رقم الحساب#//#الرقم السري#//#الاسم#//#الهاتف#//#الرصيد


## المتطلبات

- مترجم C++ (إصدار C++11 أو أحدث)
- نظام ويندوز (يستخدم `system("cls")` و `system("pause")`)
